# PulseNet web

Next.js (App Router, TypeScript). Run: `npm install` then `npm run dev`, open http://localhost:3000.

Routes: `/login`, `/signup`, `/dashboard` (overview), `/dashboard/[routers|plans|vouchers|sessions|customers|payments|agents|reports|settings]` (placeholders).
Login and signup currently just go to the dashboard. Real auth comes next. Dashboard data is sample data.
